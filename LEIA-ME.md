# JurisFlow — Como usar

## Para abrir
Dê **dois cliques em `index.html`**. Abre em qualquer navegador (Chrome, Edge, Firefox).

## Primeiros passos
1. Vá em **Configurações** e preencha: nome do escritório, logo, capa, horários de entrada/saída/almoço e o tempo do pomodoro.
2. Cadastre seus **Clientes** (CPF/CNPJ, nomes, e-mails, logo).
3. Cadastre os **Processos** (número, polos, juízo, tipo, etiquetas) — dentro de cada um você registra movimentações, desdobramentos (apelação, agravo, cumprimento de sentença…) e processos vinculados.
4. Crie **Tarefas** ligadas a cliente ou processo. Marque "É um prazo processual" para aparecer nos **Prazos ativos** do dashboard.

## Dashboard
- Semana em estilo kanban: **arraste as tarefas entre os dias** para reagendar.
- Coluna direita: prazos ativos, calendário, pomodoro (skins 🍅 ⏱️ 🌳) e a barra do seu dia (azul = manhã, cinza = almoço, amarelo = tarde, vermelho = últimos 15 min).

## Relatório em PDF
No processo, clique em **🖨 Relatório PDF** → na janela de impressão escolha **"Salvar como PDF"**. Sai com a logo do escritório e a do cliente.

## Importante: seus dados
- Tudo fica salvo **neste navegador, neste computador**. Não usa internet.
- **Faça backups**: Configurações → *Baixar backup (.json)*. Guarde no Drive. Para restaurar (ou levar para outro computador), use *Restaurar backup*.
- Se limpar os dados do navegador, os dados do sistema são apagados — por isso o backup é essencial.

## Para colocar online depois (GitHub Pages)
1. Crie uma conta em github.com e um repositório (ex.: `sistema-processos`).
2. Envie o `index.html` para ele.
3. Em *Settings → Pages*, ative o GitHub Pages.
Quando estiver online, me peça para **ativar o login Google e as integrações** (Drive, Gmail, Calendar, Meet) — a estrutura já está preparada.
